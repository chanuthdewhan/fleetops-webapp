# FleetOps — Web Application

Frontend for the FleetOps fleet & logistics dispatch system, built for the Enterprise Cloud Architecture (ITS 2130) capstone project.

## Project Description

A dispatcher and driver web interface for managing delivery orders, driver/vehicle assignments, trip tracking, and delivery notifications — consuming the FleetOps microservices backend through the API Gateway.

## Technology Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- React Router
- TanStack Query
- Axios
- React Hook Form + Zod
